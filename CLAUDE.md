# CLAUDE.md

Сервис регистрации на мероприятия (тестовое задание, junior agentic developer).

## Правила работы (действуют всю сессию)

1. Работаем маленькими шагами. После каждого завершённого шага делай git commit с понятным сообщением.
2. Веди DECISIONS.md. Каждая запись начинается с метки времени из `date -Iseconds` (не выдумывай время). Пиши, что решили, почему, и какие альтернативы отбросили.
3. Каждый инвариант из списка ниже закрывается автотестом. Гонки проверяй параллельными запросами.
4. Не делай всё за один заход. Остановись после каждого этапа и покажи, что сделано.
5. Если что-то не работает или не сделано, честно фиксируй это для README.

## Обязательное поведение (инварианты)

- Повторная регистрация на тот же email не создаёт второго места.
- Отказ → первый из листа ожидания автоматически получает место и письмо.
- Двое на последнее место одновременно → место одному, второй в листе ожидания.
- Напоминание за сутки до события, ровно одно.
- Билет проходит чекин один раз, счётчик у организатора обновляется live.
- Перенос события → письмо всем участникам.
- Работает при двух открытых вкладках. После перезапуска сервера ничего не теряется.

## Стек

Node.js + TypeScript + Fastify, PostgreSQL + Drizzle, pg-boss (фоновые задачи), Mailpit (заглушка почты),
React + Vite + TypeScript + Tailwind, SSE для realtime, Vitest + Playwright. Всё поднимается через docker compose.

## Структура

npm workspaces, монорепо:
- `/backend`: Fastify API
- `/frontend`: React SPA

## Окружение

- Node установлен через nvm: в неинтерактивном shell сначала `source ~/.nvm/nvm.sh`.
- Docker Desktop должен быть запущен для `docker compose`.
